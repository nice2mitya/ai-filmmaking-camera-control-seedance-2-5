# PRD06f-GlambotWideArc

Вариант [PRD06-Glambot](../PRD06-Glambot/). Облёт 90° вместо 47°. Занавес, дорожка и ограждение расширены, чтобы 20 мм не выходил за край декорации (при 120° выходил).

Код: `engine/cinematic/src/templates/products/p06f-glambot-widearc.ts` (генерится `tools/variants/glambot.py`).
Рендер: `cd engine/cinematic && tools/render-pill.sh PRD06f-GlambotWideArc`.
